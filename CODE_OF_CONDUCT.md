# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2.1/code_of_conduct/) version 2.1.

Be respectful in issues, pull requests, and reviews. Harassment and personal attacks are not accepted. Report conduct problems through the same private channel as [SECURITY.md](SECURITY.md). Maintainers may remove comments, close threads, or reject contributions that break this standard.
